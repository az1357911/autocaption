개인정보 처리방침

시행일: 2026년 10월 13일

요약: 자동 자막의 음성 인식과 자막 분할은 모두 사용자의 Mac에서 이루어집니다. 개발자는 서버를 두고 있지 않으며, 사용자의 비디오, 오디오, 자막 또는 어떠한 개인정보도 수집하거나 저장하지 않고 볼 수도 없습니다. 사용자가 직접 클라우드 AI 번역 또는 AI 교정을 선택한 경우에만 자막 텍스트가 사용자가 선택한 서비스로 전송되며, 처음 전송하기 전에 먼저 사용자에게 묻습니다.

1. 사용자의 Mac에서 처리되는 데이터

  • 비디오 및 오디오: 앱은 사용자가 패널로 드래그한 Final Cut Pro 프로젝트가 참조하는 미디어 파일을 읽고, Apple의 음성 인식(SpeechAnalyzer)을 사용하여 Mac에서 텍스트로 변환합니다. 미디어 파일은 어디에도 업로드되지 않습니다.
  • 자막 분할: Apple의 온디바이스 Apple Intelligence 모델(Foundation Models)을 사용하여 Mac에서 처리합니다.
  • Apple 번역: ‘Apple 번역’을 선택하면 macOS에 내장된 번역 기능을 사용하여 Mac에서 처리합니다.
  • 설정 및 고유 명사 목록: 사용자의 Mac에만 저장됩니다.
  • API 키: 사용자가 입력한 AI 서비스 키는 macOS 키체인에 저장되며, 해당 서비스에 직접 연결하는 데만 사용되고 개발자에게 전송되지 않습니다.
  • 진단 기록: 앱은 사용자의 Mac에 간단한 작업 기록을 남길 수 있으며(파일 이름만 기록하고 전체 경로는 기록하지 않음), 이 기록은 누구에게도 자동으로 전송되지 않습니다.

2. 사용자가 선택한 경우에만 제3자에게 전송되는 데이터

  • 클라우드 AI 번역 및 AI 교정: 설정에서 클라우드 AI 서비스(예: OpenAI, Anthropic, Google 등)를 선택하고 본인의 API 키를 입력하면, 앱은 자막 텍스트, 고유 명사 목록, 번역을 위해 입력한 추가 설명을 사용자가 선택한 서비스로 직접 전송합니다. 처음 전송하기 전에 앱은 전송할 내용을 설명하고 동의를 요청하며, 사용자는 언제든지 ‘설정 > 번역’에서 동의를 철회할 수 있습니다. 이 데이터는 해당 서비스가 자체 개인정보 처리방침에 따라 처리하므로, 해당 서비스의 약관을 참조하십시오. 로컬 서비스(Ollama, LM Studio)를 사용하는 경우 데이터는 사용자의 컴퓨터 밖으로 나가지 않습니다.
  • AI 모델 목록: 클라우드 AI 서비스를 사용하면서 앱이 모델을 자동으로 고르도록 하면, 앱은 사용자의 키로 해당 서비스에 사용 가능한 모델 목록을 조회하고, OpenRouter에서 공개된 모델 목록과 가격을 다운로드합니다(계정이나 키가 필요 없으며, 자막 내용이나 개인정보는 일절 포함되지 않습니다).
  • 음성 인식 및 번역 모델: 어떤 언어를 처음 사용할 때 macOS가 Apple에서 해당 음성 인식 모델 또는 번역 모델을 다운로드하며, 이는 Apple이 자체 개인정보 처리방침에 따라 처리합니다.

3. 구독 및 결제
